# 6 GitHub Repos That Will Teach You ML Better Than Any Course

> Free. Open source. Built by the people who actually ship this stuff at Microsoft, NVIDIA, and Google.
> Bookmark this and work through them in order.

`// codewithboi`

---

## 1. Generative AI for Beginners

**Repo:** [microsoft/generative-ai-for-beginners](https://github.com/microsoft/generative-ai-for-beginners)

**Maintained by:** Microsoft

**Best for:** absolute beginners to GenAI

A 21 lesson course that takes you from "what even is a token" to building real GenAI apps. Each lesson has a video, a written explainer, code samples, and a homework challenge.

**What you will learn:**
* How LLMs actually work and why they hallucinate
* Prompt engineering that goes beyond "be a helpful assistant"
* Building with Azure OpenAI, Hugging Face, and open models
* RAG, fine tuning, and function calling from first principles
* Responsible AI and how to evaluate what you shipped

---

## 2. NVIDIA Deep Learning Examples

**Repo:** [NVIDIA/DeepLearningExamples](https://github.com/NVIDIA/DeepLearningExamples)

**Maintained by:** NVIDIA

**Best for:** intermediate learners who want production grade code

State of the art deep learning implementations, straight from the team building the GPUs that train these models. Every example is optimized for performance and comes with training scripts, benchmarks, and pretrained checkpoints.

**What you will learn:**
* How real training pipelines are structured (not toy notebooks)
* Mixed precision, multi GPU, and distributed training
* Reference implementations for BERT, ResNet, Tacotron, and more
* Reading and adapting research grade PyTorch and TensorFlow code
* What "production ML" actually looks like

---

## 3. AI Agents for Beginners

**Repo:** [microsoft/ai-agents-for-beginners](https://github.com/microsoft/ai-agents-for-beginners)

**Maintained by:** Microsoft

**Best for:** anyone who wants to build agents, not just chatbots

A 10 lesson course on building AI agents that can plan, use tools, and complete multi step tasks. This is the frontier right now, and Microsoft made it approachable.

**What you will learn:**
* The difference between an LLM, a chatbot, and an agent
* Agentic design patterns: planning, tool use, reflection, multi agent
* Frameworks like AutoGen, Semantic Kernel, and LangChain
* Building agents that use MCP servers and external APIs
* Evaluating agent behavior and handling failure modes

---

## 4. ML From Scratch

**Repo:** [eriklindernoren/ML-From-Scratch](https://github.com/eriklindernoren/ML-From-Scratch)

**Maintained by:** Erik Linder Norén

**Best for:** learners who want to understand ML at the math level

Every classic ML algorithm implemented in pure Python and NumPy. No scikit learn, no PyTorch, no shortcuts. If you have ever used `.fit()` without knowing what happens next, this repo fixes that.

**What you will learn:**
* Linear and logistic regression from the loss function up
* Decision trees, random forests, and gradient boosting internals
* Neural networks, CNNs, and RNNs built layer by layer
* K means, PCA, and unsupervised methods you can actually explain
* The math that every "ML engineer" job description assumes you know

---

## 5. Homemade Machine Learning

**Repo:** [trekhleb/homemade-machine-learning](https://github.com/trekhleb/homemade-machine-learning)

**Maintained by:** Oleksii Trekhleb

**Best for:** visual learners and Jupyter notebook people

Similar spirit to ML From Scratch, but delivered as interactive Jupyter notebooks with clear math, plots, and explanations for each algorithm. Great as a companion or a gentler entry point.

**What you will learn:**
* Regression, classification, and clustering explained visually
* The intuition behind each algorithm before the code
* How to read and write the math notation in ML papers
* Interactive demos you can tweak and rerun
* A solid mental model for when to reach for which algorithm

---

## 6. MCP for Beginners

**Repo:** [microsoft/mcp-for-beginners](https://github.com/microsoft/mcp-for-beginners)

**Maintained by:** Microsoft

**Best for:** developers who want their AI to actually do things

Model Context Protocol is how modern AI apps connect to tools, data, and services. This course walks you through building MCP servers and clients from scratch, in multiple languages.

**What you will learn:**
* What MCP is and why it is becoming the standard
* Building your first MCP server in Python, TypeScript, or C#
* Connecting MCP servers to Claude, VS Code, and other clients
* Security, authentication, and best practices
* Real world use cases you can ship this week

## Bonus: Google Cloud Generative AI

**Repo:** [GoogleCloudPlatform/generative-ai](https://github.com/GoogleCloudPlatform/generative-ai)

**Maintained by:** Google Cloud
**Best for:** anyone building GenAI on GCP or curious about Gemini

Hundreds of notebooks and sample apps showing how to build with Gemini, Vertex AI, and the rest of the Google Cloud AI stack. Excellent counterweight to the OpenAI centric tutorials everywhere else.

**What you will learn:**
* Building with Gemini across text, image, video, and audio
* Vertex AI for training, tuning, and serving models
* Retrieval, embeddings, and vector search on GCP
* Agent Builder and production grade GenAI patterns
* How the same concepts translate across cloud providers

---

## How to actually use this list

1. Pick **one** repo. Not three.
2. Clone it, run the first example, break it, fix it.
3. Finish it before moving on.

The people who learn ML are not the ones who bookmark the most repos. They are the ones who finish one.
